# 硕士学位论文格式对照说明

本模板的硕士论文部分依据研究生院《西南交通大学研究生学位论文撰写范式》（2024 年 7 月版）实现。为便于核对与后续维护，下表给出「范式要求 → 模板实现」的对照关系。

## 1. 页面设置

| 项目 | 范式要求 | 模板实现 |
| --- | --- | --- |
| 纸张 | A4（21.0 cm × 29.7 cm） | Typst 默认 A4 |
| 页边距 | 上、下、左、右各 3.0 cm，装订线 0 | `doc` 在 `doctype: "master"` 时传入 `margin: 3cm` |
| 页眉、页脚距边界 | 2.0 cm | 通过页边距与页眉页脚内容近似实现 |
| 前置部分页码 | 大写罗马数字 Ⅰ、Ⅱ、Ⅲ…… | `layouts/master-preface.typ` 中 `master-footer(numbering: "I")` |
| 正文页码 | 阿拉伯数字 1、2、3…… | `mainmatter` 中 `footer-style: "plain"`，`counter(page).update(1)` |

## 2. 字体与段落

| 内容 | 字体 | 字号 | 对齐 / 缩进 | 段前 / 段后 |
| --- | --- | --- | --- | --- |
| 一级标题（章） | 黑体 | 三号（16 pt） | 居中 | 24 pt / 18 pt |
| 二级标题（节） | 黑体 | 四号（14 pt） | 顶格左对齐 | 18 pt / 6 pt |
| 三级标题（条） | 黑体 | 四号（14 pt） | 顶格左对齐 | 12 pt / 6 pt |
| 四级标题（款） | 黑体 | 小四（12 pt） | 顶格左对齐 | 12 pt / 6 pt |
| 正文 | 中文宋体、英文 Times New Roman | 小四（12 pt） | 两端对齐，首行缩进 2 字符 | 0 / 0 |
| 页眉 | 宋体 | 五号（10.5 pt） | 居中 | — |
| 页码 | Times New Roman | 小五（9 pt） | 居中 | — |
| 图题 | 宋体 | 五号 | 居中（图下方） | 6 pt / 12 pt（近似） |
| 表题 | 宋体 | 五号 | 居中（表上方） | 12 pt / 6 pt（近似） |
| 参考文献 | 宋体 | 五号 | 两端对齐，悬挂缩进 | 0 / 0 |

行距：从中文摘要开始，正文与标题均取固定值 20 磅。Typst 无「固定行距」属性，模板通过 `text(top-edge: 0.75em, bottom-edge: -0.25em)` 配合 `par(leading: 8pt)` 实现 20 磅行距（`1em + 8pt = 12pt + 8pt`）。

## 3. 前置部分

| 页面 | 页眉 | 页码 |
| --- | --- | --- |
| 中文封面、英文扉页 | 无 | 无 |
| 独创性声明、使用授权 | 无 | 无 |
| 中文摘要 | 摘 要 | Ⅰ 起 |
| ABSTRACT | ABSTRACT | 连续罗马数字 |
| 目录 | 目 录 | 连续罗马数字 |
| 图目录 / 表目录 | 图目录 / 表目录 | 连续罗马数字 |
| 主要符号表 / 缩略词表 | 主要符号表 / 缩略词表 | 连续罗马数字 |

## 4. 正文与结尾部分

- 页眉统一为「西南交通大学硕士学位论文」，五号宋体居中，单横线 0.75 磅；
- 章、节、条标题按上表设置，章标题自动另起一页；
- 图表按章编号（图 1-1、表 1-1），表采用三线表（上下边线 1.5 磅、栏目线 1 磅）；
- 参考文献采用 GB/T 7714-2015 顺序编码制，五号字、悬挂缩进；
- 附录自动编号为「附录 A」「附录 B」……；
- 致谢、参考文献、附录、攻读学位期间成果的顺序与范式一致（致谢在参考文献之前）。

## 5. 与 Word 范式的已知差异

1. Word 的「固定行距 20 磅」以近似方式实现，字号变化时行距会随字号略有变化；
2. 图题、表题、公式的段前段后距采用 Typst 的块间距（相邻间距取较大值），与 Word 的累加方式略有不同；
3. PDF 中不插入双面打印用的空白背页，以保证页码连续；空白背页在双面打印时自然产生；
4. 未实现国家图书馆封面、书脊与博士学位论文格式。
