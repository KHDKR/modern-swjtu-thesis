# 西南交通大学硕士论文模板审计报告

审计日期：2026-10-26。审计对象：`feat/swjtu-master`，起始提交 `67b7f75`。

本轮已修改代码并验证实际 PDF，修复了封面填写栏、标题和数学字体、双面分页、长表续排、文献格式与分页等问题。本科示例与两份基线的 16 页渲染像素完全一致。**专业学位独立封面的官方依据仍不足，不将“专业型已全面符合独立封面规范”标记为通过。** 下文按项目分别给出证据与限制；编译成功不等于全部规范通过。

### 封面复核更正（用户反馈后）

初版将封面填写栏标为通过时，漏掉了标签分散对齐未生效的问题。行内box中的弹性空白没有拉开字距，实际标签与官方范式不符；示例还人为指定了三行题目。此次将标签改为原生等分grid，二字/四字标签均占96.02pt，填写线从271.75pt到431.73pt；填写内容按用户明确要求在每条下划线上居中，续行分别居中。示例题目改为原生自动换行。另修正单位代码与英文提交说明、英文题目、日期的基线，并调整中文题目下划线。

新增`tests/cover-official.typ`与`scripts/check_cover.py`。中文标签逐字与官方PDF比较，最大原点坐标差0.340pt；中文五行填写线、英文说明/题目/日期基线均有坐标断言。正式示例14行已填写内容、长字段用例10行内容逐行断言相对填写线中心误差小于0.1pt。该数值只针对列出的元素，不代表整个封面的所有字形逐像素一致。相同题目的中英文对照图为`build/audit/cover-comparison-1.png`和`cover-comparison-2.png`；其中原Word中文日期未填写月日，Typst显示实际日期，蓝色说明框仅保留在官方侧。

## 6. 未确认项与适用边界

1. **专业学位独立封面未通过规范完备性验收。** 现有Word未给出第二套封面，更没有“专业学位类别（领域）”标签的样式依据。已验证professional内容配置、电子和双面输出；保留现有有依据标签，并开放`major-label`。在获得对应官方封面前不能宣称已验证该独立版式。
2. **书脊、国家图书馆封面、博士及博士后输出未提供本轮合规结论。** 书脊在原规范§2.12有要求，但独立印制还依赖成册厚度，本轮交付论文正文PDF与双面排页，不生成书脊印制文件。
3. **印刷设备流程未实际走纸验证。** PDF的正背页、空白页和页序已检查；实际打印仍须选择按PDF物理页双面输出，不能再次让打印驱动插页。
4. **位置比较不承诺逐像素一致。** Word正文页码基线实测约761.376 pt，Typst约763.600 pt，差约2.224 pt；正文/前置页眉统一后存在字形墨迹范围差异。页码字体、字号、居中和页序已确认；不把上述差异藏在“基本符合”中。若学校要求逐点复刻而非规范参数，仍需对此作最终人工确认。
5. **Word与Typst段距模型不同。** 相邻块间距存在合并，图表单倍行距也依字体度量。规则、对应页面及边界用例已检查，但未对任意相邻浮动体组合宣称与Word数值逐点相等；作者最终稿仍应查看实际页尾与浮动体。
6. **字体替代环境未验证。** Windows指定字体已核验；macOS/Linux或其他字体配置的粗体外观、换行及数学字形需要重新渲染确认。
7. **文献数据须核对。** 新CSL的中英文期刊、显式标准类型、姓名/大小写、引用/分页已有测试；不同出版物的缺失字段、专有名词、译者、罕见体裁和数据错误不能靠模板自动判真。中文/西文etal选择依据责任者文本，混合文字姓名等特殊情况仍需人工核对。CSL不再强制将姓转为全大写，但不会可靠地纠正输入数据本身的全大写姓名；回归文献第10条仍输出原数据的`CHRISTINE`，这条数据不满足姓仅首字母大写要求，应由使用者校正。原共用`ref.bib`含占位及不规范数据；没有为保持本科基线而批量改写它。
8. **盲审不自动清洗作者正文或图片中的身份信息。** 已隐藏模板字段并清空PDF作者元数据；研究成果、致谢以外的自由内容、嵌入扫描图、文件附件须由作者自行处理。此处不作匿名安全认证。
9. **作者内容要求不等于布局函数。** 中文摘要800字/1页、致谢篇幅、文献数量与时效、缩略词排序、正文研究内容、实际签字和本人姓名加粗等，需作者按规范填写。模板不截断超长摘要，也不虚构学术成果。
